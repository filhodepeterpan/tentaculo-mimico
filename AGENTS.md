# Agent notes

- Faça perguntas se necessário quando um requisito importante não puder ser determinado pelo repositório.
- Aplicação única Maven, Java 21 / Spring Boot 4.1.1; entrypoint `src/main/java/br/com/tentaculomimico/TentaculoMimicoApplication.java`. `./mvnw spring-boot:run` inicia; `./mvnw test` testa; foco: `./mvnw -Dtest=DoacaoServiceTest test` (troque pela classe desejada). Build Docker: `./mvnw clean package -DskipTests`.
- `CursoMapeamentoTest` verifica conversões Mongo (snake_case, ObjectId, datas/horas) sem banco: `./mvnw -Dtest=CursoMapeamentoTest test`. Testes que carregam o contexto/integradores exigem configuração externa.
- Fluxo geral: controller → service → repository. Controllers mantêm binding HTTP e montagem de views; regras e gravações novas devem ficar nos services. Controllers/services aplicam verificações de sessão via `SessaoService`; não presuma que as permissões de URL protegem uma rota nova.
- `model/` mistura documentos Mongo e modelos somente de resposta; verifique `@Document`, `@Field` e `MongoConfig` antes de alterar persistência. Consulte `docs/data_dictionary.md`, `docs/ddl_banco/` e `docs/requisitos.md` para contrato de dados e regras, confirmando no código porque requisitos podem não estar implementados.
- UI é Thymeleaf renderizado no servidor (`templates/fragments/` contém componentes). Preserve textos e erros de domínio em português brasileiro; não grave formatação exclusiva de apresentação nos dados persistidos.
- Pagamento de matrícula é simulado por padrão (`app.pagamento.simulado=true`); doações usam PagBank e não são o mesmo fluxo. Configuração obrigatória em `application.properties`: `MAIL_HOST`, `MAIL_PORT`, `MAIL_USER`, `MAIL_PASSWORD`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `MONGO_URI` e `CLOUDINARY_URL`. O URI Mongo usa `spring.mongodb.uri` (Boot 4). `.zed/` contém configuração local/possíveis credenciais e `target/` é saída de build; não os copie para arquivos versionados.
