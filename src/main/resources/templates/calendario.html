Professor, utilize o calendário para cadastrar um curso

🕒 Os cursos só podem acontecer entre 07:00 e 22:00 e não podem começar em um dia e horário que já passaram. As áreas listradas não aceitam horário. Para cadastrar na semana que vem, use PRÓXIMA SEMANA.

Como uso o calendário para cadastrar um curso?

🖰 Utilizando o MOUSE, CLIQUE em um horário livre, ARRASTE para mover, PUXE as bordas para esticar e confirme em ✓. Para escolher mais de um dia, segure SHIFT e CLIQUE em outro dia: o horário é o mesmo em todos. Use ✗ para tirar um dia.
🖮 Utilizando o TECLADO, pressione TAB até o dia, ENTER para escolher, SETAS para mover, SHIFT + SETAS para esticar e + e - para aumentar ou diminuir 30 minutos. Para escolher mais de um dia, use SHIFT + ENTER para adicionar o dia ao lado, com o mesmo horário. ENTER para confirmar todos os dias e ESC para cancelar um dia por vez.
📱 Utilizando o CELULAR, TOQUE em um horário livre, ARRASTE para mover, PUXE as bordas para esticar e confirme em ✓. Para escolher mais de um dia, TOQUE E SEGURE em outro dia: o horário é o mesmo em todos. Use ✗ para tirar um dia.
